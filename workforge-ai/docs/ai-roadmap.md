# WorkForge AI roadmap

Concise learning path for this repository.

| Phase | Focus |
|------:|-------|
| 1 | ✅ **LLM** — Spring AI + Ollama chat |
| 2 | ✅ **Prompt Engineering** — templates, few-shot, strategies, preview |
| 3 | ✅ **Embeddings** — vectors, cosine similarity, compare/rank |
| 4 | ✅ **PGVector** — persist embeddings + semantic search |
| 5 | ✅ **RAG** — retrieve context, then generate grounded answers |
| 6 | ✅ **Tool Calling** — Spring AI `@Tool` + read-only WorkForge tools |
| 7 | ✅ **Agent** — controlled decide/act/observe loop over tools |
| 8 | ✅ **LangGraph4j** — explicit stateful graph (nodes/edges/loops) |
| 9 | ✅ **MCP** — separate MCP server (:8091) + client in AI backend |
| 10 | ✅ **Memory** — conversation history + explicit long-term memory (PostgreSQL) |
| 11 | ✅ **Multi-Agent** — Supervisor + Issue / Knowledge / Project specialists |
| 12 | ✅ **Evaluation / Security / Observability** — measure, guard, trace |

**Learning track complete** for Phases 1–12.

See [evaluation.md](./evaluation.md), [security.md](./security.md), [observability.md](./observability.md), [multi-agent.md](./multi-agent.md), [memory.md](./memory.md).
